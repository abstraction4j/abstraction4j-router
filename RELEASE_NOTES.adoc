= Release Notes

All notable changes are listed here, newest first.
This project follows https://semver.org/[Semantic Versioning]; before 1.0, minor versions may change the public API.

== Version 0.1.0 (unreleased)

Initial version.

* `ImplementationFinder`, the strategy that picks the implementation for each call.
* `RoutingImplementationFinder`, which routes by a key from one or more sources, tried in order: typed method arguments (`byArgument`, or `byRoutingKey` for parameters marked with `@RoutingKey`) and the current context such as the SLF4J MDC (`byContext`), chained with `or()`, with an optional default implementation. Routes can be conditional (`route(key).and(...).to(...).orElse(...)`, or `andRoutingKey(...)` for `@RoutingKey` parameters), for example on feature flags evaluated at call time.
* `JdkAbstractionRouters`, routers built on JDK dynamic proxies.
* `SpringAbstractionRouters`, routers built on Spring AOP.
* `@EnableSpringAbstraction`, which registers a `@Primary` router for every `ImplementationFinder` bean, and `@DisableRouter` to exclude a finder.
* Spring Boot auto-configuration that applies `@EnableSpringAbstraction`, controlled by `abstraction4j.router.enabled` (with IDE metadata), and a Spring Boot starter.
* Spring AOT and GraalVM native image hints for automatically registered routers.
* Kotlin support: `suspend` functions and `Flow` work through every router, and finders see nullable arguments (`Array<Any?>`).
* Java module descriptors (`module-info`) for every module.
* A CycloneDX SBOM published with every module.
* Plain Java and Spring Boot samples, and JMH benchmarks.
* Supports Java 21+, Spring Framework 7.0.1+ and Spring Boot 4.0+.
